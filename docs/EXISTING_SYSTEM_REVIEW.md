# 既存システム確認結果

## 結論

既存物から流用できるのは、Driveのフォルダ構成、本命フォーム、本命回答シート、項目名、業務区分の考え方です。GAS、帳票テンプレート、生成ロジック、テストは未実装だったため、新規実装としました。

## 確認した資産

- 引き継ぎメモ（12ページ）
- 本命の初回ヒアリングフォーム回答シート（13列、回答データなし）
- 参考用の詳細フォーム回答シート（30列、回答データなし）
- Driveの親フォルダと業務別サブフォルダ
- 空のGASフォルダ、共通テンプレートフォルダ、業務別テンプレートフォルダ

## 採用した判断

- 初期版は13列の本命フォームだけを対象にする。
- 外部APIは使わず、GAS標準サービスだけで完結させる。
- フォーム質問名への直接依存を局所化し、変更箇所を `Config.gs` にまとめる。
- フォーム送信直後の処理に失敗しても、回答はシートに残し定期処理で再試行する。
- 住所は自動整形せず、原文保存と警告に限定する。
- 法的な文面や正式な必要書類をコードで断定しない。
