# 受入確認チェックリスト

## 初期設定

- [ ] `setupAstraSystem` がエラーなく完了する
- [ ] システム列が回答シート右側へ追加される
- [ ] 管理シート3枚が追加される
- [ ] 共通テンプレート2件が指定フォルダへ作成される
- [ ] インストール型トリガーが2件作成される

## ダミー回答

- [ ] 回答がシートへ残る
- [ ] 案件IDが付与される
- [ ] 顧客別フォルダが作成される
- [ ] 申請内容確認書が作成される
- [ ] 必要書類リストが作成される
- [ ] 同じ行を通常処理しても重複生成されない
- [ ] メニューから再生成すると再生成版が作成される

## 住所・入力確認

- [ ] `1-2-1` を含む住所が要確認になる
- [ ] 住所原文が変換されず帳票へ転記される
- [ ] 同意なし回答は書類生成されない
- [ ] 必須項目なし回答は入力不備になる
- [ ] エラー内容と処理ログが確認できる

## 行政書士確認

- [ ] 正式なテンプレート文面を行政書士が承認する
- [ ] 各必要書類リストを管轄別に確認する
- [ ] 個人情報の利用目的と共有範囲を確認する
- [ ] 最終確認者と確認済みへの変更手順を決める
