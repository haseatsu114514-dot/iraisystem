# 受入確認チェックリスト

## 初期設定

- [ ] Script Properties 未設定のまま実行すると、設定を促す明確なエラーで止まる
- [ ] `setupAstraSystem` がエラーなく完了する
- [ ] システム列が回答シート右側へ追加される
- [ ] 既存の回答行（処理状態が空）が「対象外（導入前）」になり、勝手に処理されない
- [ ] 管理シート3枚が追加される
- [ ] 共通テンプレート2件が指定フォルダへ作成される
- [ ] インストール型トリガーが2件作成される

## ダミー回答

- [ ] 回答がシートへ残る
- [ ] 案件IDが付与される
- [ ] 顧客別フォルダが作成される
- [ ] 申請内容確認書が作成される
- [ ] 必要書類リストが作成される
- [ ] 同じ行を通常処理しても重複生成されない
- [ ] メニューから再生成すると再生成版が作成される
- [ ] メニューから選択行のPDFを書き出すと顧客フォルダへPDFが保存される
- [ ] 業務を自動判定できない回答が「その他」として警告付きで生成される
- [ ] 3回失敗した行が「エラー」表示になり、放置されない

## 住所・入力確認

- [ ] `1-2-1` を含む住所が要確認になる
- [ ] 住所原文が変換されず帳票へ転記される
- [ ] 顧客入力住所が書類転記住所へ暫定コピーされる
- [ ] 住民票等が未提出でも書類生成を続行できる
- [ ] 任意添付がある場合は目視照合の警告が出る
- [ ] 書類転記住所を修正して再生成すると修正後住所が使われる
- [ ] 同意なし回答は書類生成されない
- [ ] 必須項目なし回答は入力不備になる
- [ ] エラー内容と処理ログが確認できる

- [ ] 正式なテンプレート文面を行政書士が承認する
